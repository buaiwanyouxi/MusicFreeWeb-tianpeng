## 任务 2.2：分析插件加载机制并修改订阅源 ✅

### 分析结果

#### 插件加载流程
1. 用户点击"导入预设配置" → 调用 `importDefaultFeeds()`
2. 从 `${window.location.origin}/feeds.default.json` 获取订阅源
3. `fetchPluginFeed()` 解析 JSON，提取插件列表
4. 对每个插件，通过 `loadPluginInstance()` 下载并执行插件代码
5. 插件代码在 `new Function()` 沙箱中执行，注入 `module/exports/require/MusicFreeH5/fetch/console/env`
6. `adaptMusicFreePlugin()` 自动将原生 MusicFree 格式适配为 H5 格式

#### 关键发现
- **requireShim** 已提供 axios/cheerio/crypto-js/dayjs/he/qs/big-integer
- **proxiedFetch** 自动将 API 请求转发到代理
- **adaptMusicFreePlugin()** 自动适配原生插件格式

### 修改内容

#### 1. `public/feeds.default.json` — 订阅源
- 原：仅包含 QQ 音乐示例插件
- 新：包含 6 个 tianpeng 插件（bilibili、xiage、buguyy、migu、gequbao、fangpi）
- URL 指向 Gitee 仓库的 raw 直链

#### 2. `src/lib/pluginHost.ts` — URL 重写规则
新增代理规则：
- `gequbao.com` → `/api/proxy/gequbao/`
- `fangpi.com` → `/api/proxy/fangpi/`
- `tonzhon.com` → `/api/proxy/tonzhon/`
- `buguomusic.com` → `/api/proxy/buguomusic/`
- `followlyrics.com` → `/api/proxy/followlyrics/`
- `raw.giteeusercontent.com` → `/api/proxy/gitee_raw/`

#### 3. `netlify/functions/proxy.js` — Netlify 代理目标
新增代理目标：
- `gequbao` → `https://www.gequbao.com`
- `fangpi` → `https://www.fangpi.com`
- `tonzhon` → `https://tonzhon.com`
- `buguomusic` → `https://buguomusic.com`
- `followlyrics` → `https://www.followlyrics.com`
- `gitee_raw` → `https://raw.giteeusercontent.com`

#### 4. `vite.config.ts` — 本地开发代理
新增对应的 Vite 开发代理规则（与 Netlify 代理一致）
