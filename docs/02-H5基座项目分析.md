## 三、插件加载机制（核心）

### 3.1 加载方式：fetch + new Function()

```ts
const wrapped = new Function(
  'module', 'exports', 'require', 'MusicFreeH5',
  'fetch', 'console', 'env',
  `${code}\nreturn module.exports;`
);

wrapped(module, module.exports, requireShim, hostApi,
        proxiedFetch, createPluginConsole(name), env);
```

插件代码以字符串形式通过 `new Function()` 在受控沙箱中执行。

### 3.2 沙箱注入的上下文

| 变量 | 说明 |
|------|------|
| `module` | CommonJS module 对象 |
| `exports` | CommonJS exports 对象 |
| `require` | **requireShim** — 提供 axios/cheerio/crypto-js 等 |
| `MusicFreeH5` | 宿主 API（含 registerPlugin） |
| `fetch` | **proxiedFetch** — 经代理的 fetch（自动走 CORS 代理） |
| `console` | 带插件名前缀的 console |
| `env` | 环境变量（platform 等） |

### 3.3 requireShim 提供的模块

```ts
// 插件中可以直接 require 这些模块：
const axios = require('axios');       // axios shim（基于 proxiedFetch）
const cheerio = require('cheerio');   // cheerio 库
const CryptoJS = require('crypto-js'); // crypto-js 库
const dayjs = require('dayjs');
const he = require('he');
const qs = require('qs');
const BigInteger = require('big-integer');
```

**关键发现**：基座已经内置了移动端插件常用的所有依赖！

### 3.4 支持的插件格式（5种）

| 格式 | 说明 | 兼容性 |
|------|------|--------|
| `MusicFreeH5.registerPlugin(factory)` | H5 原生注册 | H5 专用 |
| `module.exports = { searchSongs, ... }` | H5 对象导出 | H5 专用 |
| `module.exports = function(ctx) { return {...} }` | 函数导出 | H5 专用 |
| `module.exports = { search, getMediaSource, ... }` | MusicFree 原生格式 | **自动适配** |
| `module.exports = { getTopLists, platform, ... }` | 最小格式（仅榜单） | **自动包装** |

### 3.5 adaptMusicFreePlugin() 适配器

**这是最关键的发现**：基座内置了 `adaptMusicFreePlugin()` 函数，可以自动将 MusicFree 原生插件（格式4）适配为 H5 格式。

这意味着：**现有的移动端插件很可能无需重写，直接就能在 H5 基座中运行！**

适配映射：
- `search` → `searchSongs`
- `getMediaSource` → `resolveStream`
- `getTopLists` → `getTopLists`
- `getMusicSheetInfo` → `getPlaylistSongs`
- `getRecommendSheetTags` → `getRecommendSheetTags`
- `getRecommendSheetsByTag` → `getRecommendSheetsByTag`

## 四、代理/CORS 处理

### 4.1 URL 重写规则

插件内的 API 请求通过 `rewriteUrl()` 自动转发到 Netlify Function 代理：

| 源 | 代理路径 |
|----|---------|
| `api.bilibili.com` | `/api/proxy/biliapi/` |
| `c.y.qq.com` | `/api/proxy/qqmusic_c/` |
| `search.kuwo.cn` | `/api/proxy/kuwo_search/` |
| `interface.music.163.com` | `/api/proxy/netease_interface/` |
| `msearch.kugou.com` | `/api/proxy/kugou_search/` |
| `musicapi.haitangw.net` | `/api/proxy/haitang/` |
| `m.music.migu.cn` | `/api/proxy/migu_m/` |

### 4.2 代理规则

- API 请求 → 走 Netlify Function 代理（解决 CORS）
- 媒体资源（图片/音频/视频）→ 直接请求，不走代理
- 开发环境可走本地代理

### 4.3 Netlify Functions 代理支持的平台

proxy.js 白名单包含：QQ音乐、酷我、网易云、酷狗、B站、海棠、咪咕、LX Music、ikun、段兄音乐等。

## 五、MusicPlugin 类型（H5 格式）

```ts
type MusicPlugin = {
  name: string;
  version?: string;
  author?: string;
  capabilities: ('search' | 'lyrics' | 'playlist' | 'stream')[];
  supportedSearchTypes?: ('music' | 'artist' | 'album' | 'sheet')[];
  
  searchSongs(query, page?): Promise<SearchResult<PluginTrack> | PluginTrack[]>;
  searchArtists?(query, page?): Promise<SearchResult<PluginArtist>>;
  searchAlbums?(query, page?): Promise<SearchResult<PluginAlbum>>;
  searchPlaylists?(query, page?): Promise<SearchResult<PluginPlaylist>>;
  resolveStream?(track: PluginTrack): Promise<PluginStream>;
  getTopLists?(): Promise<PluginTopListGroup[]>;
  getTopListDetail?(playlist): Promise<{...}>;
  getRecommendSheetTags?(): Promise<PluginRecommendTag[]>;
  getRecommendSheetsByTag?(tag, page?): Promise<SearchResult<PluginPlaylist>>;
  getPlaylistSongs?(playlist): Promise<PluginTrack[]>;
};
```

## 六、关键结论

1. **现有移动端插件大概率可以直接使用**：基座的 `adaptMusicFreePlugin()` 会自动适配
2. **requireShim 提供了所有常用依赖**：axios、cheerio、crypto-js 等
3. **代理层已覆盖所有主要音乐平台**：B站、QQ、网易云、酷狗、酷我、咪咕等
4. **只需 fork 基座 + 修改订阅源 URL 即可开始**
5. **如果插件需要特殊 API 域名**，需要在 proxy.js 和 URL 重写规则中添加
