## 核心结论

### 1. 现有插件无需重写

H5 基座项目 `zyb/musicfree-h5` 内置了 `adaptMusicFreePlugin()` 适配器，可以自动将 MusicFree 原生插件格式转换为 H5 格式。加上 `requireShim` 已提供所有常用依赖（axios、cheerio、crypto-js 等），**6 个移动端插件均有可能零改动直接在 H5 基座中运行**。

### 2. 唯一需要处理的是代理

部分插件使用的 API 域名（gequbao.com、fangpi.com、Tonzhon API）可能不在代理白名单中，需要在 `pluginHost.ts` 和 `proxy.js` 中添加。

### 3. 下一步计划

1. Fork `zyb/musicfree-h5` 到本地
2. 修改默认订阅源为 `musicfree-tianpeng.json`
3. 本地运行测试现有插件是否直接可用
4. 如有问题，针对性修复
