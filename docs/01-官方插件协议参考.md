# MusicFree 官方插件协议参考

> 来源：MusicFree 官方源码 `src/types/` + 插件模板

## 一、插件元数据（IPluginDefine）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `platform` | `string` | 是 | 插件唯一标识 |
| `version` | `string` | 否 | 版本号，如 `1.0.0` |
| `author` | `string` | 否 | 作者 |
| `description` | `string` | 否 | 描述，支持 Markdown |
| `srcUrl` | `string` | 否 | 远程更新 URL |
| `appVersion` | `string` | 否 | 适配的 App 版本 |
| `primaryKey` | `string[]` | 否 | 主键字段列表 |
| `defaultSearchType` | `SupportMediaType` | 否 | 默认搜索类型 |
| `supportedSearchType` | `SupportMediaType[]` | 否 | 支持的搜索类型 |
| `cacheControl` | `'cache' \| 'no-cache' \| 'no-store'` | 否 | 缓存策略 |
| `userVariables` | `IUserVariable[]` | 否 | 用户自定义变量 |
| `hints` | `Record<string, string[]>` | 否 | 提示信息 |

### IUserVariable

```ts
interface IUserVariable {
  key: string;
  name?: string;   // 显示名
  hint?: string;   // 输入提示
}
```

## 三、核心数据结构

### IMusicItem（歌曲）

```ts
interface IMusicItem {
  id: string;           // 平台唯一编号
  platform: string;     // 平台标识
  artist: string;       // 艺术家
  title: string;        // 标题
  duration?: number;    // 时长(秒)
  album?: string;       // 专辑名
  artwork?: string;     // 封面图 URL
  url?: string;         // 默认播放 URL
  lyric?: ILyricSource; // 歌词
  rawLrc?: string;      // 原始 LRC 歌词文本
  qualities?: Record<IQualityKey, { url?: string; size?: string | number }>;
  [key: string]: any;   // 扩展字段
}
```

### IMusicSheetItem（歌单）

```ts
interface IMusicSheetItemBase {
  id: string;
  platform: string;
  title?: string;
  artwork?: string;
  coverImg?: string;
  description?: string;
  worksNum?: number;
  artist?: string;
}

interface IMusicSheetItem extends IMusicSheetItemBase {
  musicList: IMusicItem[];
}

interface IMusicSheetGroupItem {
  title: string;
  data: IMusicSheetItemBase[];
}
```

### IAlbumItem（专辑）

```ts
interface IAlbumItem {
  id: string;
  platform: string;
  title: string;
  artwork?: string;
  description?: string;
  artist?: string;
  date?: string;
  worksNum?: number;
  musicList?: IMusicItem[];
}
```

### IArtistItem（艺术家）

```ts
interface IArtistItem {
  id: string;
  platform: string;
  name: string;
  avatar?: string;
  fans?: number;
  description?: string;
  worksNum?: number;
  musicList?: IMusicItem[];
  albumList?: IAlbumItem[];
}
```

### IMediaSourceResult（播放源）

```ts
interface IMediaSourceResult {
  url?: string;                     // 播放地址
  headers?: Record<string, string>; // 自定义请求头
  userAgent?: string;               // UA
  quality?: 'low' | 'standard' | 'high' | 'super';
}
```

### ILyricSource（歌词）

```ts
interface ILyricSource {
  lrc?: string;         // 歌词 URL（已废弃）
  rawLrc?: string;      // LRC 格式歌词文本
  translation?: string; // 翻译歌词文本
}
```

### IComment（评论）

```ts
interface IComment {
  id?: string;
  nickName: string;
  avatar?: string;
  comment: string;
  like?: number;
  createAt?: number;
  location?: string;
  replies?: IComment[];
}
```

### 搜索结果

```ts
interface ISearchResult<T> {
  isEnd?: boolean;  // 是否已到末尾
  data: T[];        // 结果列表
}
```

### 支持类型

```ts
type SupportMediaType = 'music' | 'album' | 'artist' | 'sheet' | 'lyric';
type IQualityKey = 'low' | 'standard' | 'high' | 'super';
```

## 四、插件格式规范

### 移动端/桌面端格式（CommonJS）

```js
module.exports = {
  platform: 'xxx',
  version: '1.0.0',
  author: 'author',
  description: '描述',
  
  async search(query, page, type) {
    // ...
  },
  
  async getMediaSource(musicItem, quality) {
    // ...
  },
  // ... 其他方法
};
```

### 要求

- JavaScript ES7+，CommonJS 模块
- 可使用纯 JS 第三方依赖（不能有 native 依赖）
- 所有方法均为异步（返回 Promise）
- 方法均为可选，实现哪些就暴露哪些
